# 걸음걸이 정서 인식 연구 정리

이 문서는 저장소의 구현을 기준으로 **걸음걸이 정서 인식 연구를 다시 읽기 쉽게 정리한 개요 문서**입니다.  
API 사용법보다, **무엇을 연구하고 있고 어떤 구조로 실험/배포 자산이 나뉘어 있는지**를 빠르게 파악하는 데 초점을 둡니다.

---

## 1. 연구 목표

이 연구의 핵심 질문은 다음과 같습니다.

> **사람의 걸음걸이만으로 정서 상태를 구분할 수 있는가?**

텍스트, 음성, 얼굴 표정 없이도 걸음걸이에는 속도, 보폭, 좌우 대칭성, 자세 변화처럼 정서와 연관될 수 있는 단서가 존재합니다.  
이 저장소는 그러한 단서를 **정량 특징(HCF)** 과 **시계열 표현(Bi-LSTM)** 으로 함께 다루는 구조를 취합니다.

---

## 2. 문제 정의

### 입력

- 프레임별 신체 키포인트 좌표
- 또는 키포인트를 `"x,y,z"` 문자열 배열로 평탄화한 `skeleton_data`

### 출력

- 6개 정서 클래스 중 하나
  - Happy
  - Sad
  - Fear
  - Disgust
  - Angry
  - Neutral

### 연구 포인트

1. **비언어적 정서 인식**
2. **시간 흐름에 따른 보행 패턴 해석**
3. **해석 가능한 특징과 시계열 모델의 결합**

---

## 3. 현재 저장소 기준 연구 파이프라인

1. **키포인트 수집**
   - MediaPipe 등으로 사람의 관절 좌표를 얻습니다.
2. **전처리**
   - `src/feature_extractor.py`에서 문자열 좌표 파싱, 루트 센터링, 최소 프레임 패딩을 수행합니다.
3. **특징 추출**
   - 14개의 HCF(Hand-Crafted Features)를 계산합니다.
4. **정서 예측**
   - 추출 특징을 기반으로 배포용 모델이 감정을 추론합니다.
5. **API 반환**
   - `src/main.py`가 감정 라벨, 신뢰도, 확률분포를 JSON으로 반환합니다.

---

## 4. 14개 HCF 특징을 연구 관점에서 보면

`src/feature_extractor.py`는 특징을 다음 다섯 범주로 나눕니다.

### A. Kinematics

- 평균 속도
- 최대 속도
- 속도 표준편차
- 평균 가속도
- 평균 저크

→ **정서에 따른 보행 리듬과 에너지 차이**를 포착합니다.

### B. Body Parts

- 손 움직임
- 발 움직임
- 좌우 대칭성

→ **팔/다리의 활동성, 긴장감, 불균형** 같은 단서를 반영합니다.

### C. Volume

- 바운딩 박스 부피 평균

→ **몸을 얼마나 크게 쓰는지**를 근사적으로 나타냅니다.

### D. Posture

- 머리 기울기
- 척추 길이

→ **위축/개방 자세** 같은 정서 신호를 간접적으로 담습니다.

### E. Joint Variance

- 움직임 분산이 큰 상위 3개 관절

→ 어떤 관절이 **정서별로 더 크게 변화하는지**를 반영합니다.

---

## 5. 모델 전략 요약

README 기준으로 이 프로젝트는 **Bi-LSTM HCF Fusion**을 최종 배포 전략으로 소개합니다.

- **Bi-LSTM**: 시간에 따른 키포인트 변화 패턴을 읽음
- **HCF**: 해석 가능한 보행 특징을 제공
- **Fusion**: 시계열 표현과 정량 특징을 함께 사용

즉, 이 연구는 단순히 "정확도가 높은 분류기"를 만드는 것보다,

1. **시계열 정보의 활용**
2. **특징 해석 가능성 확보**
3. **배포 가능한 API 형태로의 연결**

을 동시에 고려한 구조로 볼 수 있습니다.

## 7. 현재 성능을 어떻게 해석할 것인가

README에 정리된 주요 수치는 아래와 같습니다.

| 모델 | 특징 | 정확도 | 해석 포인트 |
|:--|:--|:--|:--|
| Bi-LSTM HCF Fusion | Raw + HCF | 96.42% | 시계열 + 특징 결합의 배포 기준 |
| KNN | HCF 14개 | 96.99% | 전통 ML도 강한 성능을 보일 수 있음을 시사 |
| Bi-LSTM | Raw only | 94.66% | 시계열만으로도 높은 성능 확보 |
| Random Forest | HCF 14개 | 72.81% | 특징 기반 비교 모델 |
| SVM | HCF 14개 | 34.42% | 선형/전통 모델 한계 비교 |

이 표는 연구를 다시 정리할 때 다음 질문으로 이어질 수 있습니다.

- 왜 KNN이 높은 정확도를 보였는가?
- 배포 모델은 왜 Fusion인가?
- 정확도 외에 **실시간성/일반화/해석 가능성** 중 무엇을 더 중시했는가?
